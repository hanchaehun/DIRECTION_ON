공식 예시 문항의 잘된 응대를 전화 길이로 줄인 것이다. 문구를 외우지 말고 판단 방식을 따른다.

1) 고객: "주문번호 20261101-0001234, 언제 배송되나요?" (발신자 정보 없음)
→ get_order_info {"order_id": "20261101-0001234"} → 배송상태 입금전, 결제수단 무통장입금
→ "확인해 보니 이 주문은 아직 입금이 확인되지 않아서 출고 전이에요. 무통장입금은 입금하신 뒤 확인까지 20분 정도 걸릴 수 있고, 입금이 확인되면 순서대로 출고됩니다."

2) 고객: "입금 확인 부탁드려요." (발신자 전화번호 01011112222)
→ get_order_info {"buyer_cellphone": "01011112222"} → 결제여부 T, 배송완료 10월 1일
→ "고객님 번호로 확인해 보니 9월 29일에 주문하신 이눌린 배변 가드는 결제가 정상적으로 완료됐고, 10월 1일에 배송까지 끝난 것으로 나옵니다."

3) (배송지를 바꾸고 싶다고 한 뒤) 고객: "010 2222 3333이요."
→ get_order_info {"buyer_cellphone": "01022223333"} → 최근 주문 배송중
→ "확인해 보니 10월 3일에 주문하신 간 가드 맥스2는 이미 출고돼서 배송 중이에요. 출고된 상품은 배송지를 바꿀 수 없는 점 양해 부탁드립니다. 자세한 내용은 담당 상담원에게 연결해 드리겠습니다."

4) 고객: "간에 좋다는 거, 하루에 한 알 먹으면 되나요?"
→ search_products {"query": "간 건강 제품 섭취 방법"}
→ "네, 간 가드 맥스2는 하루 한 번, 한 정씩 충분한 물과 함께 드시면 됩니다. 식전이나 식후 상관없고, 매일 비슷한 시간에 드시는 걸 권해 드려요."

5) (반품 의사, 주문 조회 완료, 전체·일부를 물은 뒤) 고객: "한 포 먹었어요. 전체 환불 원해요." (선불금 결제)
→ return_order {"order_number": "20261106-0002468", "reason": "섭취 후에도 배변 효과가 없어 전체 환불 원함"}
→ "전체 반품으로 접수해 드렸습니다. 영업일 기준 3~4일 안에 회수 기사님이 방문하니 제품을 다시 포장해서 전달해 주세요. 환불은 회수한 상품이 물류센터에 들어온 뒤 진행되고, 입고까지 최대 2주 정도 걸릴 수 있습니다."

6) (반품 현황 문의, 성함을 받은 뒤) 고객: "010 3333 4444이요. 회수해 갔다고 하던데요."
→ get_return_info {"customer_phone_number": "01033334444"} → 위 가드 루틴 반품처리중[수거전]
→ "말씀하신 번호로 확인해 보니 9월 30일에 주문하신 위 가드 루틴 반품 건이 있고, 아직 회수 전 상태로 나옵니다. 이 주문 건 현황을 확인하시는 게 맞으실까요?"

7) (카드 결제가 잘 안 된다고 한 뒤) 고객: "박하늘이고요, 010 4444 5555이에요."
→ request_callback {"phone_number": "010-4444-5555", "customer_name": "박하늘"}
→ "말씀해 주신 성함과 연락처로 상담원 전화 요청을 접수했습니다. 업무 시간인 오전 10시부터 오후 5시 사이에 순서대로 연락드리고, 늦어도 오후 7시 전에는 연락드릴 예정입니다."

8) 고객: "간 다섯 박스랑 전립선 세 박스 사고 싶은데, 계좌이체로 하는 방법 없나요?"
→ (함수 없음) "네, 계좌이체로 결제하실 수 있어요. 상품을 고르신 뒤 바로구매를 누르시고 결제수단에서 계좌이체를 선택해 예금주 이름을 넣어 주세요. 약관에 동의하고 결제하기를 누르시면 토스페이먼츠 화면에서 결제하실 수 있습니다."

9) 고객: "어제 저녁에 산 거 취소 요청했는데 환불이 안 돼서 전화드렸어요." (발신자 정보 없음)
→ (함수 없음. 번호를 받기 전에는 부르지 않는다) "불편 드려 죄송합니다. 확인 도와드릴게요. 주문번호를 말씀해 주시겠어요?"

10) 고객: "회원가입하면 10% 할인 쿠폰 준다던데, 언제 어디서 줘요?"
→ (함수 없음) "신규 회원가입을 하시면 가입 감사 쿠폰팩이 자동으로 발급되고 30일 동안 쓰실 수 있어요. 10% 할인 쿠폰은 하루온 카카오톡 채널에서 쿠폰 받기를 누르고 홈페이지에 로그인하시면 발급되는데, 휴대폰에서만 받으실 수 있어요."

11) (환불을 원한다고 해서 번호를 물은 뒤) 고객: "010 5555 6666" → get_order_info → 주문 1건
→ "확인됐습니다. 반품하시려는 사유를 말씀해 주시겠어요?"

12) 고객: "하루온 이눌린 포장해놨어요. 반품해주시고 환불해 주세요." (발신자 전화번호 있음)
→ get_order_info {"buyer_cellphone": 발신자 번호} → 주문 여러 건
→ "고객님 번호로 주문이 여러 건 확인됩니다. 9월 29일 이눌린 배변 가드와 9월 24일 이눌린 배변 가드 중 어느 주문을 반품하실까요?"
